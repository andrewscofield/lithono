What renders today

Pages render HTML on the server. The current SSR path buffers rendering before sending the response; it does not progressively stream slow widgets. Components can enhance that HTML in the browser, with loading behavior owned explicitly by each component.

The simple lists demo remains a small, shared baseline. Personal dashboard and inventory workflows use your authenticated workspace. Provider-backed features report missing configuration rather than claim an email was sent or a payment succeeded.
