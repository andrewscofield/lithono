How this page works

Application-authored ownership metadata: URL owns project/range; one dashboard-view URL-state instance coordinates GET searches/history and disposes its subscription on disconnect. The layout loader owns navigation and public identity. The page loader returns plain JSON metrics, milestones and activity. All repository reads and actions are scoped to the authenticated workspace.

  • Summary: HTML-only static fragment, no component JavaScript.
  • Status: ordinary vanilla HTMLElement, explicit normal registration import; native forms are owned by the page form controller.
  • Chart: ordinary Lit shadow SVG, explicit import, server snapshot input only; native table is the semantic alternative.
  • Notes: Lithono light TS/HTML/CSS trio, opt-in action context and a component-owned unsaved draft. Textarea value synchronizes only when clean.
  • Chart controls: browser-only Web Awesome switch, dynamically inserted on explicit menu activation and loaded via the optional element mapping. Native metric details remain usable without JavaScript.
  • Counter: explicit delayed dynamic import, local state independent of notes/status.
